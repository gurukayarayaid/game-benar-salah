Unggah Soal ke Firestore

Menyalin bank soal bawaan (210 soal, 7 mapel × 3 tingkat) ke database

Siap.

Cara menyiapkan Firestore

1. Buka console.firebase.google.com, buat proyek lalu tambahkan aplikasi Web.
2. Menu Build → Firestore Database → Create database.
3. Menu Project settings → General → Your apps: salin Project ID dan Web API Key.
4. Aturan sementara agar halaman ini bisa mengunggah (ganti setelah selesai): allow read, write: if true;
5. Klik Unggah bank soal bawaan. Setiap soal menjadi satu dokumen: { mapel, tingkat, soal, jawaban, penjelasan }.
6. Setelah selesai, isi kolom Firestore di menu ⚙ halaman game (bisa sekali saja — nilai disimpan di perangkat), atau simpan konfigurasi ke berkas www/game/firebase-config.json agar semua perangkat langsung memakainya.

Bila muncul pesan 403 PERMISSION_DENIED, aturan Firestore masih menolak tulis untuk pengunjung anonim — ubah aturannya seperti langkah 4.
